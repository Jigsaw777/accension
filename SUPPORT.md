# Getting help

Start with `accs doctor` and `accs logs`. The [troubleshooting guide](TROUBLESHOOTING.md) explains common problems. Ask usage questions and share recipe ideas in [GitHub Discussions](https://github.com/Jigsaw777/accension/discussions).

For a reproducible bug, open an [issue](https://github.com/Jigsaw777/accension/issues/new/choose). Include your operating system, Python and Accension versions, expected behavior, and a minimal example. Review diagnostic bundles before attaching them. Remove private code, provider keys, personal paths and account information.

Report vulnerabilities through [private vulnerability reporting](https://github.com/Jigsaw777/accension/security/advisories/new). Do not put exploit details or credentials in a public issue or Discussion. Community support has no guaranteed response time.
