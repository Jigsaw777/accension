# Code of conduct

Be respectful and constructive. Welcome different experience levels. Critique ideas and code without attacking people. Do not harass, discriminate, threaten, impersonate others or publish their private information.

Maintainers may edit or remove harmful content and restrict participation. Decisions should be proportionate and explained where doing so respects privacy. For a conduct concern, contact `@Jigsaw777` privately through an available GitHub channel; do not post another person's private details publicly. For software vulnerabilities, use the separate [security reporting process](SECURITY.md).

This policy applies to project issues, PRs, Discussions and other spaces managed by the project.
